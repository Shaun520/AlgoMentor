> 适用阶段：立项前（0 → 1）

---

## 一、项目定位回顾

AlgoMentor 的目标是一站式的「AI 求职备战 Agent 平台」，核心模块：

| 模块 | 形态 | 关键能力 |
| --- | --- | --- |
| 笔试刷题系统 | 左题面 / 右 IDE | 判题、测试用例、复杂度分析 |
| 八股背诵记忆 | 知识点 + 场景题 + 选择题答题系统 | 记忆曲线、答题统计 |
| AI 面试官 | 对话式 | 简历导入（含 OCR）、语音输入与识别、追问 |
| Chat Agent | 自然语言操作全系统 | 新增题目（自动生成测试用例）、新增八股、生成场景题 |

一句话定位：**把「刷题 + 八股 + 模拟面试 + 系统操作」四条原本割裂的链路，用一个统一学习者模型和多个协作 Agent 串成一个闭环。**

## 二、竞品调研

### 2.1 调研范围

按用户求职准备的真实链路（找题 → 刷题 → 背八股 → 模拟面试 → 复盘）拆成四类竞品：

1. **题库/八股内容平台**：面试鸭、小林 coding、牛客题库
2. **刷题 + AI 辅助**：LeetCode/力扣、AlgoExpert、Marauder Bot、Interactive LeetCode MCP、LockedIn AI
3. **AI 模拟面试 / 面试辅助**：面多多、面灵 AI、牛客 AI 面试、Interviewing.io、Exponent(Pramp→Aced)、Final Round AI、MockInterviewAI、Yoodli、Huru
4. **教学式 AI / 学习操作系统**：Khanmigo、DeepTutor（HKUDS 开源）

### 2.2 国内竞品

**① 面试鸭（mianshiya.com）——最直接的对标对象**

- 2024 年 8 月上线，定位「程序员面试刷题平台」，8000+ 题，覆盖 Java / C++ / Python / Go / 前端 / 后端 / 测试 / 运维 / 计算机基础 / 408 等近百个方向。
- 三端：网页 + 微信小程序 + IDE 插件，账号互通。
- 商业模式：**全部题库免费**，129 元起的会员买的是「大厂面试官原创题解 + 错题本」。
- 关键缺口：**明确不做模拟面试**。官方与第三方评测都指出，它只解决「知道答案」，解决不了「开口讲清」「抗追问」。

**② 面多多（ai.mianshiya.com）——面试鸭同生态的 AI 模拟面试**

- 沉浸式综合面试（自我介绍 → 项目深挖 → 技术拷问 → 综合评估）。
- 专项面试（Java/Redis/Spring/MySQL/HR 面等 400+ 方向）。
- **简历押题**：上传简历预测面试官提问，给解题思路、追问与相关题目。
- 输出个性化面试报告。

> 结论：国内「题库」与「AI 面试」已分别被面试鸭 + 面多多、牛客各占一头，但两者仍是**两个割裂的产品**，数据不互通。

**③ 牛客网——体量最大的平台型选手**

- 1000 万+ C 端用户、2000+ 付费企业客户；笔试支持 10 万人并发，10W+ 题目、30+ 语言、AI Coding 测评 + 9 大防作弊手段。
- AI 面试基于 3000 万+ 面试数据训练，强调多语种与「替代 83% 初面」。
- 学生端有题库、竞赛、面经社区；**AI 模拟面试覆盖 10 大岗位 + 100+ 企业真题，会生成面试报告**。
- 关键缺口：面向**企业招聘**为主，C 端备考是引流；学习闭环（错题归因 → 复习编排 → 二次训练）较弱。

**④ 面题鸭 / 面灵 AI —— 轻量 AI 面试新势力**

- 面题鸭：**上传岗位截图自动生成专属押题库**，每题带业务场景 + 开发实践 + 考点溯源。
- 面灵 AI：按简历 + 目标岗位提问，输出表现打分与短板分析的复盘报告。

**⑤ 八股「背诵类」工具（跨品类但强相关）**

- Anki / 速记卡 / 背书帮 / 刻记：基于 SM-2 / FSRS 的间隔重复、挖空、双链、批量导入、学习热力图、TTS 朗读、错题集。
- 小林 coding / 小林面试笔记：74 道 AI/Agent/RAG/LLM 面试题、600+ 手绘图解、25 万+字，全部免费，靠内容 IP 变现课程。

> 结论：**八股背诵工具是通用记忆工具，不含「面试场景 + 选择题答题系统 + 与刷题/面试联动的错题归因」**，这是明确空白。

### 2.3 海外竞品

**① 刷题侧**

- **LeetCode/力扣**：3000+ 题、公司题单、每周竞赛；Premium 内置 AI assistant，提供**不给答案的提示（hints）**、最优解讲解。
- **Marauder Bot**：浏览器侧栏「读题 → 返回结构化题解（代码 + 时空复杂度 + 分步推理）」，支持 GPT/Claude/Gemini 多模型对比，覆盖 LeetCode/HackerRank/截图。
- **Interactive LeetCode MCP**：面向 Claude Code 的 MCP，含 **4 级渐进提示（hint ladder）** 与「学习引导模式」：理解题 → 规划思路 → 编码 → 优化 → 提交复盘。
- **LockedIn AI**：面试中实时编码辅助（作弊向，有合规风险）。

**② AI 模拟面试 / Copilot 侧**

- **Interviewing.io**：免费 AI 面试官（算法 + 系统设计）+ 真人 FAANG 面试官（约 $179/次）。
- **Exponent（Pramp → Aced）**：P2P 同伴模拟面试，约 $79/月，讲究「真实人类提问」。
- **Final Round AI**：10M+ 用户、76 语言；8 类面试场景（General/Coding/System Design/Behavioral/PM/Data-ML/薪资/Recruiter），**面试后有 debrief + re-drill（重练弱项）**；另有实时 Interview Copilot（合规争议大）。
- **MockInterviewAI**：语音 AI 面试官 + 实时代码编辑器 + 系统设计白板，10 语言，€19.99/月——**功能组合最接近本项目**。
- **Yoodli**：只做表达/口语层面的 delivery 教练（口头禅、节奏、自信度），$8–28/月。
- **Huru AI**：对求职者免费，主打 mock 练习库。

> 结论：海外工具普遍**英文优先、无中文八股、无「题库造题」能力**，且「刷题」与「面试」仍是两个产品。

**③ 教学式 AI / 学习操作系统**

- **Khanmigo（Khan Academy）**：Socratic（苏格拉底式）教学标杆，**「永不给答案」**、hint ladder、代码 review；$4–9/月。已验证：不给答案会让一部分用户不耐烦流失，但留下的用户长期能力提升明显。
- **DeepTutor（HKUDS 开源，Apache-2.0，3.4 万+ star）**：把 Chat / Deep Solve / Quiz / Deep Research / Visualize / **Mastery Path** 放进同一 Agent 运行时；**Knowledge Graph Memory** 记录薄弱点；**TutorBot** 有独立记忆与人格；支持 MCP / Skills 被其他 Agent 调用。是目前「学习操作系统」思路的最强开源参照。

### 2.4 个人/开源项目

- 力扣用户「高乐高」的 **leetcode 家教 agent**：学习画像 + 艾宾浩斯计划一键导入 + 复盘讲解 + 笔记自动分类。
- **InterviewMate**（Streamlit + Llama + Whisper）：简历解析 → 按简历/岗位生成题 → 语音作答 → 打分/缺失点/改进建议 → 结课报告。
- **AI Hiring Agent**（Django + Claude + Vapi）：简历原生 PDF 打分 → 自动语音电话面试 → 转录分析 → 排名。

> 说明：这类项目「单点都能做」，说明**单模块技术门槛不高**，胜负手在**系统化串联 + 工程化质量 + 前端体验**。

### 2.6 调研结论

1. **「刷题」与「八股」与「面试」在国内是三家公司、三个产品**（面试鸭/面多多、牛客、各类 AI 面试工具），数据不互通，用户要在多个 App 之间来回搬运。
2. **AI 面试工具普遍只做「输出层」**（问 + 打分 + 报告），不做「输入层」的题库沉淀与复习编排，也**不做跨模块的薄弱点回流**。
3. **「教学式 AI（不给答案、苏格拉底）在编程面试场景几乎是空白**——Khanmigo 覆盖通识与基础编程，LeetCode/MCP 只有简单 hint ladder，没有针对算法面试的「引导状态机」。
4. **「用 Chat Agent 自然语言造题（自动配测试用例）」没有竞品**——现有平台的题目全部由平台方生产，用户无法一分钟造出一道带多组测试用例的题。
5. **「可运行的系统设计沙盘」没有竞品**——MockInterviewAI 有静态白板，但没有「参数可调 → 指标实时变化」的仿真。
6. **中文技术面试的表达/抗追问训练被严重低估**——Yoodli 只练 delivery，国内 AI 面试只给报告，没有人练「面试官打断追问」。

## 三、差异化空白点（Gap Analysis）

| 编号 | 空白点 | 现状 | 机会 |
| --- | --- | --- | --- |
| G1 | 单一数据源 vs 多源融合 | 各模块独立 | 打通「刷题/八股/面试」表现，形成统一能力画像 |
| G2 | 只判对错，不判「为什么错」 | 靠 tag/难度 | 错因分类（知识点/审题/边界/复杂度） |
| G3 | 只给答案，不教推导 | 题库是静态题解 | 苏格拉底式引导 + hint ladder 状态机 |
| G4 | 只练「输入」，不练「输出」 | 面试报告给完就结束 | 复盘 → 自动生成二次训练任务 |
| G5 | 题目由平台生产 | UGC 门槛高 | Agent 造题（题目 + 多组测试用例 + 题解） |
| G6 | 系统设计靠「说」 | 白板是静态的 | 可运行仿真沙盘，参数 → 指标 |
| G7 | 单面试官 | 一个 AI 只问一类题 | 多 Agent「面试官天团」+ 互相追问 |
| G8 | 黑盒评分 | 「你 7 分」无依据 | 可解释评分 + 证据链（引用哪行代码/哪次回答） |

## 四、已有 4 个创新点的评估与强化

以下是用户已提出的 4 点，逐条给出**竞品对应、差异化强度、可强化方向、风险**。

### 创新 1：苏格拉底式引导 Agent

- **竞品对应**：Khanmigo（通识，不给答案 + hint ladder）、Interactive LeetCode MCP（4 级提示）、LeetCode Premium hints。
- **差异化强度**：中高。空白在于**「面向算法面试、带持久引导状态、按用户每轮回答动态调深度」**的组合。
- **强化方向**：
  - 引导状态用 LangGraph 显式维护（`hint_level`、`已确认掌握的子概念`、`卡点类型`），而不是让 LLM 即兴发挥。
  - 借鉴 Khanmigo 的 **hint ladder**：`问思路 → 指方向 → 给结构性框架（留白）→ 举相似例题`，且**连续答对后逐级降阶**（回到用户主导）。
  - 新增**「反背题」判定**：让用户用自然语言复述思路，Agent 判断是真理解还是背答案。
- **风险**：用户要答案而不给会流失（Khanmigo 已验证）；需要设计「一键看题解」的逃生舱，并记录「你这次用了直达答案」以影响画像。

### 创新 2：多 Agent 协作代码评审

- **竞品对应**：Khanmigo 代码 review（单 Agent）、GitHub Copilot/CodeRabbit（工程向，非教学向）。**面向学习者的多 Agent 评审是空白**。
- **差异化强度**：高（技术叙事也好，契合「多智能体协作」面试考点）。
- **强化方向**：
  - LangGraph **fan-out / fan-in** 并行 4 节点（正确性/复杂度/风格/拓展）+ 汇总节点；用 `Annotated[List, operator.add]` 聚合结果。
  - **正确性 Agent 必须调用沙箱执行**（不能只让 LLM 说「看起来对」）；复杂度 Agent 用**实测 + 静态分析**双通道，并与历史最优解对比。
  - 汇总 Agent 输出**分级发现**（critical/warning/info）+ **去重**，避免 4 个 Agent 各说一遍。
  - 加 **Pydantic 结构化输出校验**，防止「worker 返回空 → 汇总当成成功」的级联失败（多 Agent 系统的高频生产 bug）。
- **风险**：成本与延迟（4 次调用）；需要并发上限与超时降级。

### 创新 3：前端沉浸式交互

- **竞品对应**：MockInterviewAI（编辑器 + 白板分屏）、Marauder Bot（侧栏）、LeetCode（IDE）。**行内批注 + 调试动画 + 思路可视化**无人完整做过。
- **差异化强度**：高，且**正好是你的前端优势**，是最容易做出口碑的护城河。
- **强化方向**：
  - 代码行右侧**行内批注**（类似 IDE code review gutter），点击展开证据链。
  - **执行可视化**：指针移动、变量快照、递归栈、链表/树/图的结构动画（可先做排序、双指针、BFS/DFS、链表反转这几类高频题型）。
  - **思路可视化**：把解法生成流程图 / 思维导图（可复用 `动态 UI` 的 SVG/Mermaid 思路）。
  - **三屏联动**：题面 / 编辑器 / Agent 助手，支持专注模式与联动高亮（Agent 提到「边界条件」→ 编辑器高亮 `while` 行）。
- **风险**：动画工程量与性能；建议**先做 5 类高频题型的模板化动画**，再考虑通用化。

### 创新 4：知识点知识图谱 + 错题归因

- **竞品对应**：DeepTutor 的 Knowledge Graph Memory（最接近，且是开源强参照）、Anki 的 tag 体系、面试鸭的错题本（只做收集）。
- **差异化强度**：高，但**DeepTutor 已经证明可行**，需要做出迭代差异。
- **强化方向**：
  - 图谱骨架可参考：`数组 → 双指针 → 滑动窗口`、`图 → BFS/DFS → 拓扑排序`、`DP → 背包/区间/状态机` 等。
  - 归因不止 tag：区分 **概念缺失 / 审题偏差 / 边界处理 / 复杂度误判 / 实现细节**，每类给不同训练动作。
  - 错题自动挂到图谱节点，**沿图谱向上找「前置薄弱节点」**，而不是只补当前节点。
- **风险**：图谱维护成本，建议先用**结构化种子图谱 + LLM 辅助挂载**，不追求全自动。

## 五、新增创新点（除已有 4 点外）

按「核心护城河 / 体验层 / 增强层」分组，每条给出**设计思想 / 技术实现 / 与竞品差异**。

### A. 核心护城河（决定产品不可替代性）

---

#### 创新 5：统一学习者模型 —— 三源数据融合的能力画像 ★★★

**设计思想**
刷题、八股答题、AI 面试三处表现，全部写入**同一个学习者模型**，形成一张动态能力画像，并驱动三个模块互相推荐。

**技术实现**
- 一张 `learner_profile` 存储：知识点掌握度（图谱节点权重）、错因分布、表达能力指标、遗忘状态。
- 三处以统一 `evidence` 结构写入：`{模块, 知识点, 表现, 错因, 证据引用, 时间}`。
- 用 LangGraph 的「画像更新节点」作为各流程的公共出口（面试结束、答题结束、提交结束都走同一节点）。

**示例闭环**
> AI 面试里「Redis 缓存击穿」答得含糊 → 画像标记该节点弱 → 自动推送对应八股选择题 + 一道「设计缓存」场景题 → 三天后按遗忘曲线再测 → 通过则降权。

**与竞品差异**：面试鸭/面多多、牛客、各类 AI 面试工具**都是独立产品**，这是 AlgoMentor 最本质的差异化，也是「一站式」的真正含义。

---

#### 创新 6：JD / 简历驱动的「备考剧本」★★

**设计思想**
以「目标公司 + 岗位 JD + 我的简历」为输入，自动生成一条**端到端备考路线**，而不只是押题。

**技术实现**
- Pipeline：简历（PDF/OCR）→ JD 解析 → 能力要求抽取 → 匹配画像找 gap → 生成「周计划」：算法题单 + 八股重点 + 面试剧本 + 模拟面试人设。
- 可复用面题鸭的「岗位截图 → 押题库」思路，但**延伸到题单/复习/面试全链路**。

**与竞品差异**：面题鸭只做「押题」，Final Round AI 只做「按 JD 出面试题」，**没人把它串成一条可执行的备考剧本**。

---

#### 创新 7：可运行的系统设计沙盘 ★★★

**设计思想**
八股场景题（秒杀、缓存击穿、限流、消息队列削峰…）不再只是问答，而是**一个可交互仿真沙盘**：拖组件、调参数，实时看 QPS / 延迟 / 命中率 / 积压变化。

**技术实现**
- 前端：拓扑画布（拖拽节点 + 连线） + 参数面板 + 实时指标图。
- 后端：轻量离散事件仿真（队列 / 缓存 / 限流器模型），可用 Python/TS 实现，不需要真实分布式环境。
- Agent 角色：根据用户搭建的方案**提问与挑战**（「你的缓存没有过期时间，考虑下雪崩」），并给出评分。

**与竞品差异**：MockInterviewAI 的白板是**静态的**；牛客的「实时协同白板」也是静态协作。**「参数 → 指标」的仿真在面试备考领域是空白**，且极适合前端发挥。

---

#### 创新 8：多 Agent「面试官天团」—— 压力面 / 群面 ★★

**设计思想**
不止一个 AI 面试官。至少三个角色同场：**技术面试官 + 压力面试官 + HR**，可互相插话、交叉验证，模拟压力面与群面。

**技术实现**
- LangGraph 多 Agent + 共享对话状态；用 Supervisor 模式由「主持人 Agent」调度发言权与追问。
- 压力面试官：针对答案里含糊点连续追问（「你刚说『大概』，具体数字是多少？」）。
- HR Agent：可对技术结论提出质疑，检验表达与一致性。
- 结构化输出 + 边界校验，避免角色串味（参考多 Agent supervisor 的 worker cascade failure 问题）。

**与竞品差异**：所有竞品都是**单面试官**。多角色互相追问是「抗追问训练」的最强形态。

---

#### 创新 9：Chat Agent 作为「可审计的造题/造内容操作层」★★★

**设计思想**
用自然语言直接操作整个系统：新增笔试题（**自动配多组测试用例 + 题解 + 难度/标签**）、新增八股、生成场景题，且**每一步可预览、可审计、可回滚**。

**技术实现**
- 把系统能力 MCP 化：`create_problem`、`generate_test_cases`、`validate_solution`（沙箱跑官方解验证用例）、`create_quiz`、`create_scenario`、`update_graph`。
- Chat Agent 作为 Orchestrator 调用这些工具；写操作走「草稿 → 校验（用例能否区分正确/错误解）→ 人工确认 → 入库」四步。
- 生成测试用例后**必须用「标准解 + 至少一个错误解」跑一遍**，确保用例有效（这是防垃圾题的关键）。

**与竞品差异**：现有平台题目全部由平台生产，**用户无法一句话造出一道带多组测试用例的题**。这也直接呼应你提到的「可新增笔试题目、自带多项测试案例」。

#### 创新 10：复盘 → 二次训练闭环（Re-drill Loop）★★

**设计思想**
面试/答题结束不是终点，而是**自动生成针对性再训练任务**的起点，形成「练 → 测 → 归因 → 再练」。

**技术实现**
- 复盘报告 → 抽取 Top-N 薄弱点 → 分别生成：一道同类算法题、一组八股选择题、一个场景题、一段面试追问。
- 任务进入统一「今日待办」，并纳入遗忘曲线调度。

**与竞品差异**：Final Round AI 有 re-drill 但只在面试内部；**跨模块的再训练闭环无人做到**。

---

#### 创新 11：费曼式主动回忆 + 遗忘曲线编排 ★

**设计思想**
八股复习不是「翻答案闪卡」，而是让 AI **逐层追问「为什么」**，逼你主动回忆（费曼技巧），并结合遗忘曲线安排何时追问。

**技术实现**
- 每张八股卡带「追问链」；用户答对表层后 Agent 追问下一层。
- 追问深度与复习间隔由遗忘状态 + 掌握度共同决定（复用创新 5 的画像）。

**与竞品差异**：Anki 系是**静态问答**，没有动态追问；这正好复用你的苏格拉底 Agent（创新 1）。

---

#### 创新 12：语音口语表达 + 抗追问训练（中文技术表达教练）★

**设计思想**
语音输入不止做转录，还要分析**表达层**：口头禅、逻辑断点、语速、停顿、答非所问，并结合技术内容给出改进。

**技术实现**
- ASR（Whisper 类）→ 文本；同时做声学特征（停顿/语速/填充词）+ LLM 逻辑结构分析。
- 抗追问：压力面试官（创新 8）针对「逻辑断点」处连续追问。

**与竞品差异**：Yoodli 只练 delivery 且英文；国内 AI 面试只出报告。**中文技术表达 + 抗追问**是空白。

---

#### 创新 13：可解释评分 + 证据链（Explainable Feedback）★★

**设计思想**
所有 AI 评分都给「凭据」：代码问题引用到行、八股问题引用到知识点、面试评分引用到具体哪句回答。杜绝黑盒。

**技术实现**
- 结构化输出强制带 `evidence[]`（`file/line`、`kb_node`、`transcript_span`、`confidence`）。
- 前端把证据渲染成可点击锚点，点击跳转到对应位置（呼应创新 3 的行内批注）。

**与竞品差异**：多数工具只给分；DeepTutor 有 Memory Graph 但偏学习记录。**「评分 + 证据 + 跳转」是体验差异点**。

#### 创新 14：错因归因模型（不只分类，而是定位「为什么」）

在错题标签之外，加入错因维度：`概念缺失 / 审题偏差 / 边界处理 / 复杂度误判 / 实现细节 / 表达不清`，每类对应不同训练动作（概念→讲解+八股；审题→拆题训练；边界→专项用例；复杂度→分析训练）。

#### 创新 15：一题多解 / 多语言对照

同一道题给出多种解法（暴力 → 优化 → 最优）与多语言实现，Agent 讲**权衡**而非只给最优解。适合体现对「复杂度对比」的理解。

#### 创新 16：组队互面 + AI 裁判（社交/游戏化）

两名用户组队，一人当面试官（Agent 在旁辅助出题与评分），一人作答；AI 做裁判与复盘。既解决「没人陪练」，也自带传播。参考 Exponent/Pramp 的 peer mock，但用 AI 降低「面试官」门槛。

#### 创新 17：代码执行可视化调试动画

见创新 3，可独立成卖点：双指针移动、递归栈、链表/树/图结构变化可视化，配合「单步执行 + 变量快照」。

## 七、技术架构映射（供实现参考）

```
前端 (Vue3 + TS + Tailwind)
  ├─ 三屏布局：题面 / 代码编辑器(Monaco) / Agent 助手
  ├─ 行内批注层、证据锚点跳转
  └─ 可视化层：执行动画、思路流程图、系统设计画布

后端 / Agent 编排 (Python + LangGraph)
  ├─ 苏格拉底引导图：perceive → diagnose → hint(level) → respond → update_profile
  ├─ 代码评审图：fan-out [正确性|复杂度|风格|拓展] → 沙箱工具 → fan-in 汇总
  ├─ 面试图：supervisor（主持人）→ {技术|压力|HR} → 复盘 → 生成再训练任务
  └─ 公共节点：learner_profile 更新（三源统一写入）

工具层 (MCP 化，供 Chat Agent 与各 Agent 复用)
  ├─ run_code(sandbox)              沙箱执行
  ├─ create_problem / generate_test_cases / validate_solution
  ├─ create_quiz / create_scenario / update_knowledge_graph
  └─ parse_resume(OCR) / asr(语音)

数据层
  ├─ 题目 / 测试用例 / 八股 / 场景题
  ├─ knowledge_graph（知识点图谱）
  └─ learner_profile（能力画像 + 证据链 + 遗忘状态）
```

**关键工程注意点**
1. 代码沙箱必须**隔离 + 限资源 + 限时长**（正确性评审和造题校验都依赖它）。
2. 多 Agent 的每个 worker 输出**用 Pydantic 校验**，失败要返回显式错误而不是空值（避免级联失败）。
3. 造题必须「标准解 + 错误解」双跑校验，否则会产出一堆无法区分对错的垃圾用例。
4. 简历 OCR 建议**以「原生文档解析优先，OCR 兜底」**（PDF 直接送多模态模型比 OCR 再转文本更保真）。
5. 成本控制：并行 Agent 加并发上限、超时降级、结果缓存。

## 八、风险与落地建议

| 风险 | 说明 | 建议 |
| --- | --- | --- |
| 苏格拉底模式流失 | 用户要答案被拒会烦躁（Khanmigo 已验证） | 提供「直接看题解」逃生舱，并记录行为影响画像 |
| LLM 判题/评分不靠谱 | 黑盒评分会击穿信任 | 正确性必须跑沙箱；所有评分带证据链 |
| 题库版权/合规 | 搬运力扣/牛客题目有风险 | 自有 + AI 生成 + UGC，标明来源 |
| OCR 简历识别不准 | 版式复杂易失败 | 原生文档解析优先，OCR 兜底，允许人工校正 |
| 多 Agent 成本与延迟 | 4 次并发调用成本翻倍 | 并行 + 缓存 + 弱模型跑风格/拓展 |
| 知识图谱维护成本 | 全自动不可靠 | 种子图谱 + LLM 辅助挂载，人工可纠 |
| 范围过大 | 四模块全做会失焦 | 先做深「刷题 + 引导 + 评审 + 画像」，再扩八股/面试 |

**建议的推进顺序**
1. 先立「统一学习者模型 + 数据契约」（创新 5/13）——这是所有模块的地基。
2. 做透「刷题 + 苏格拉底引导 + 多 Agent 评审 + 前端体验」（创新 1/2/3）——最容易出彩、最能讲技术。
3. 扩「八股 + 选择题 + 遗忘曲线 + 费曼追问」（创新 4/11）。
4. 扩「AI 面试官天团 + 语音表达 + 简历识别」（创新 8/12）。
5. 最后收口「Chat Agent 操作层 + 造题 + 沙盘」（创新 7/9）。
