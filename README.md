# AlgoMentor

面向技术岗校招 / 社招的一站式 AI 求职备战平台。把「算法刷题、八股背诵、AI 模拟面试、系统级 Agent 操作」四条原本割裂的链路，用一个统一学习者模型与多智能体协作串联成闭环。

## 核心模块

| 模块 | 形态 | 关键能力 |
| --- | --- | --- |
| 笔试刷题系统 | 左题面 / 右 IDE | 判题、多组测试用例、复杂度分析、行内代码批注 |
| 八股背诵记忆 | 知识点 / 场景题 / 选择题 | 间隔重复、答题系统、薄弱点归因 |
| AI 面试官 | 对话式 | 简历导入（含 OCR）、语音输入、多角色追问 |
| Chat Agent | 自然语言操作全系统 | 新增题目（自动生成测试用例）、新增八股、生成场景题 |

## 差异化方向

- **统一学习者模型**：刷题、八股、面试三源数据写入同一能力画像，跨模块互相推荐，形成「练 → 测 → 归因 → 再练」闭环。
- **苏格拉底式引导 Agent**：基于引导状态机与渐进提示，引导用户自行推导，而非直接给出答案。
- **多 Agent 协作代码评审**：正确性、复杂度、风格、拓展四路并行评审并由汇总节点输出报告，正确性由代码沙箱实测验证。
- **知识图谱 + 错因归因**：错题沿图谱定位前置薄弱节点，区分概念缺失、审题偏差、边界处理、复杂度误判等错因。
- **可运行的系统设计沙盘**：八股场景题以可交互仿真呈现，参数调整实时反映 QPS、延迟、命中率等指标。
- **沉浸式前端交互**：行内批注、执行过程可视化、思路流程图、三屏联动。

完整调研与创新点分析见 [docs/竞品调研与创新点分析.md](docs/竞品调研与创新点分析.md)。

## 技术栈（规划）

- 前端：Vue 3 + TypeScript + Tailwind CSS，Monaco 编辑器，可视化动画
- Agent 编排：LangGraph（状态机、多智能体协作、记忆与画像）
- 工具层：MCP 化（代码沙箱、造题与测试用例生成、简历解析、语音识别）
- 数据层：题目 / 测试用例 / 八股 / 场景题 + 知识点图谱 + 学习者画像
